WebHomeTV 站点列表 — Windows x64 绿色文件夹版

【适用范围】
本版本供 Windows 10/11 x64 本机使用。它是从原 WebHomeTV 项目拆出的独立站点目录工具，不需要启动虚拟机，也不读取虚拟机中的文件、数据库、Python 环境或配置。

【运行方式】
1. 解压完整文件夹到本机有写入权限的位置。不要只移动或复制 EXE。
2. 双击“启动站点列表.exe”（也可双击“启动站点列表.bat”）。
3. 程序启动本机服务并自动打开浏览器，地址为 http://127.0.0.1:9981/。
4. 首次运行时会自动创建 data\site_list.db。导入 JSON 或订阅后，配置保存在此文件中。

【绿色目录结构】
启动站点列表.exe   程序入口
_internal\         Python、依赖库及网页资源（不可删除）
data\               本机配置数据库（首次运行自动创建）
README.txt           使用说明
停止站点列表.bat     停止程序

【功能边界】
保留 JSON 文件导入、网络订阅读取、请求头设置、配置持久化及站点列表展示/筛选。网络订阅由本地服务请求，可使用 User-Agent、Referer 和额外请求头，减少浏览器跨域限制。
此独立版不执行站点 API，不含 Python Spider、JavaScript Spider、QuickJS，也不含右侧“站点操作”面板。

【安全提示】
本地服务仅监听 127.0.0.1，不向局域网开放。不要公开分享含 token、Cookie 的订阅链接或请求头。未签名的自制 EXE 可能触发 Windows SmartScreen 或杀毒软件提示。
