如何添加到手机桌面？
安卓 Chrome / Edge：打开 HTTPS 网页后点击“安装到手机”；若没有按钮，打开浏览器右上角菜单，选择“安装应用”或“添加到主屏幕”。
iPhone / iPad：使用 Safari 打开网页，点击底部“分享”，选择“添加到主屏幕”。
首次联网打开后会缓存网页外壳；断网时可重新打开界面，但远程站点请求仍需要网络。

支持 HTTP / HTTPS 文件直链。批量下载将逐个请求并触发浏览器下载；浏览器可能询问是否允许多个文件下载。大文件会暂存在浏览器内存中，建议优先使用稳定的直链。遇到 CORS 时请配置本页的 Cloudflare Worker；Worker 不能绕过登录、验证码、权限校验或防盗链。

坚果云跨设备配置同步

使用坚果云 WebDAV 保存加密同步文件。电脑和手机的解析历史自动合并；配置同时发生修改时会询问你，不会静默覆盖。

需要先在坚果云「账户信息 → 安全选项 → 第三方应用管理」生成应用密码。同步主密码不是坚果云密码；请在电脑和手机使用同一主密码。应用密码会使用同步主密码加密保存在本设备；云端同步文件使用 AES-GCM 加密。首次设置后本设备可自动解锁密钥，以支持到期自动同步。
